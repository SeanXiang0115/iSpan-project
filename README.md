# 饗島

一款以地圖搜尋、篩選的「美味座標」為入口，配合協助商家上架商品的「質感選物」購物平台，提供一站式的整合解決方案。

---

## 📖 專案簡介

「饗島」旨在打造一個兼具**美食地圖**與**質感電商**的綜合平台。用戶可以透過直觀的地圖介面（美味座標）搜尋與預約心儀的餐廳；而商家則能透過直覺的管理後台，進行店位設定、營業管理以及商品上架。

## 🛠️ 本人負責核心功能

在「饗島」專案中，我主要負責 **店家管理 (Store Module)** 與 **訂位預約 (Reservation Module)** 兩大核心技術區塊，涵蓋從資料庫設計、後端 API 開發到前端響應式介面的完整實作。

### 1. 店家管理模組 (Store Management)
- **商家個人檔案**：支援店家基本資料、店家簡介。
- **商家標籤分類管理**：基於 **多對多 (Many-to-Many)** 關係設計，讓商家具備彈性的標籤自定義功能（如：日式、景觀、深夜食堂），為前端「美味座標」地圖篩選提供核心資料。
- **形象圖處理**：實作 `MultipartFile` 圖片上傳邏輯，具備自動更名（store_id + timestamp）與伺服器端路徑管理，確保資料不衝突且可追蹤。
- **營業設定**：動態建立與維護店家的 `OpenHour` (常規營業時間) 與 `OffDay` (特定日/星期休假規則)。
- **座位配合作業**：針對不同類型的座位（如 2人座、4人座等）進行庫存總量設定，作為訂位系統的運算基礎。

### 2. 訂位預約系統 (Reservation System)
- **實時可用時段運算**：
    - 開發高效演算法，結合「營業時間」、「店休規則」與「現有訂單」，動態計算並過濾出可預約時段。
    - 支援根據座位類型（客人人數）精確配對可用桌位。
- **併發安全控制**：
    - 針對高流量訂位情境，於資料庫層級使用 **悲觀鎖 (Pessimistic Locking, `SELECT ... FOR UPDATE`)**，徹底杜絕同一個座位在同一秒被多人重複預約（Overbooking）的問題。
- **自動化通知機制**：
    - 整合 `MailService`，在訂位成功、修改或取消時，同步發送結構化 Email 通知客戶（包含預約細節與狀態提示）。
- **訂位流程管理**：支援客戶端的軟刪除（取消預約）與商家端的後台資料修改查驗。

## 🚀 使用技術 (Tech Stack)

### 後端 Backend (Java / Spring Boot)
- **框架**：Spring Boot 3.5.10 (Java 17)
- **資料庫持久化**：Spring Data JPA
- **資料庫系統**：Microsoft SQL Server (MSSQL)
- **安全性**：Spring Security + JWT (無狀態認證)
- **輔助工具**：Lombok, Spring Mail, Hibernate (Pessimistic Locking)

### 前端 Frontend (Javascript / Vue.js)
- **核心框架**：Vue 3 (Vite 構建)
- **地圖整合**：Leaflet (用於美味座標地圖呈現)
- **UI 元件庫**：PrimeVue (表格、彈窗、日期選取)
- **狀態管理**：Pinia
- **通訊協定**：Axios (攔截器處理 JWT)
- **樣式與主題**：Bootstrap 5 + SASS

## 🔍 技術邏輯解析 (Logic Highlights)

### 💡 標籤處理與資料關聯
商家可以自由勾選多樣化的標籤。在後端實作中，我們採用了 `Category` 實體與 `StoresInfo` 的 Many-to-Many 關聯。當商家更新標籤時，系統會自動處理中間表的紀錄維護，確保前端在進行地圖熱門篩選時，能精準過濾出符合條件的優質店家。

### 💡 時段過濾邏輯
在 `BookingService` 中，我們不只是檢查有沒有營業，還會逐一比對每個時段區間是否撞到店休。例如，如果店家設定了「每星期三 14:00-16:00 不收客」，預約系統會自動將該小時從 UI 選項中移除。

### 💡 資料一致性保證
為了應對熱門店家被搶位的情況，我們在 `createBooking` 事務中使用 `seatRepository.findByIdForUpdate`。這確保了從讀取到寫入期間，同一店家的特定座型資料被行鎖 (Row Lock) 保護，保證在多執行緒環境下，剩餘桌數永遠計算準確。

## 🗺️ 使用指南 (User Guide)

### 對於一般消費者
1. **探索**：進入首頁後，透過「美味座標」地圖找尋周邊商家，或使用篩選器選擇想吃的類別。
2. **預約**：進入商家頁面選擇「預約」，系統會依據剩餘量顯示綠色可選時段，紅色則為不可選。
3. **管理**：在個人中心可查看所有預約記錄，並支援在預約日前進行個人化資訊更新或取消。

### 對於合作商家
1. **商家註冊與管理**：入駐平台後，可透過「店家設定」上傳亮眼的形象圖吸引客人。
2. **營運設定**：設定好時段間隔與用餐限時後，系統會自動產出對應的預約清單。
3. **即時檢閱**：商家後台可一覽當日所有預訂姓名與電話，便於現場帶位安排。
